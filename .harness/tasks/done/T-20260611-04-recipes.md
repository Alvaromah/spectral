# T-20260611-04 — Remaining recipes (05, 08-12)

Status: done (2026-06-11, commit `8ada5b7`)
Areas: recipes

## What was done

The planned cookbook set, each with recipe.asm + demo.asm + test.json,
`zxs test recipes` now 12/12:

- `05-sprite-masked-16x16` — (screen AND mask) OR data, 2x2 cells, halo
  mask; format per line: maskL, dataL, maskR, dataR.
- `08-im2-isr` — `im2_init` builds the 257-byte table at run time
  (page 0xFE, filler 0xFD, JP isr at 0xFDFD). Test pins the frame counter
  at N-1 of the budget (runs stop right after interrupt acceptance).
- `09-beeper-fx` — `beep` keeps border bits in every OUT; `fx_zap` sweep.
  Headless = no audio, so the test asserts the contract: terminates,
  border intact, loop healthy.
- `10-score-bcd` — `score_add` (ADD+DAA, DJNZ preserves the decimal
  carry), `score_print` (nibble split + RST 0x10). User defines `score`.
- `11-prng` — Metcalf 16-bit xorshift. Expected bytes cross-validated
  against an independent JS model (also confirmed period 65535, no zero).
  Seed must never be 0.
- `12-attr-effects` — `attr_addr` (byte-identical to templates/game/lib),
  `attr_fill_rect`, `attr_rotate_row` (LDDR marquee).

## Conventions worth keeping

- Tests pin deterministic outcomes empirically (golden-style) — fine
  because same boot + inputs ⇒ bit-identical RAM.
- Demos put inspectable state at fixed EQU addresses (0x9000+) so
  `memEquals` can see it.
- Cross-recipe reuse via `INCLUDE "../NN-name/recipe.asm"`.
