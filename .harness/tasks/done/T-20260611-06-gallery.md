## What was done

`gallery/` — static, no build step, all relative paths (GitHub Pages
ready). `index.html` renders cards from `games/index.json` +
per-game `meta.json`; `player.html?game=<id>` boots the vendored
zx-generation ESM bundle and loads the game's `.z80`.

Key integration facts (cost a session to learn — don't rediscover):

- zx-generation's real browser API: `new ZXSpectrum('#screen', { rom,
  scale, sound, autoStart, onReady })`. `onReady(spectrum)` fires after
  the ROM loads and BEFORE autoStart — load snapshots there with
  `spectrum.loadZ80Snapshot(uint8)`. The `ready` event in API.md does
  not exist in the bundle (LLM-generated docs); use the option callback.
- The bundle default-fetches the ROM from the jsDelivr CDN — pass
  `rom: '48k.rom'` to stay local. `48k.rom` + ROM-COPYRIGHT.md vendored.
- Game snapshots: `zxs run` to a good moment, `zxs state export --z80`.
  zxs emits z80 v1 (49,182 bytes uncompressed) which upstream loads.
- Verified with headless Chrome
  (`--headless=new --screenshot --virtual-time-budget`): both pages
  render, the Pong snapshot runs in-browser.
